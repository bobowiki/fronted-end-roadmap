
## 🚀 嵌入式系统学习 24 周全路线图（从零到独立开发）

> 每周 5 天学习 + 2 天复盘/实践。
> 平均每天 1–2 小时，适合自学者或在职进阶。
> 默认使用 **STM32F4/Nucleo** 或 **ESP32** 开发板（都可通用）。

---

### **第 1 阶段：基础巩固（第 1–4 周）**

目标：打牢 C 语言、硬件与电路基础，点亮第一个 LED。

#### **第 1 周：C 语言快速复习**

**学习目标：**

* 理解变量、指针、数组、结构体、函数与作用域
* 掌握 `volatile`、`const`、`static` 在嵌入式中的意义

**每日任务：**

| 天数    | 任务                          | 练习                    |
| ----- | --------------------------- | --------------------- |
| Day 1 | 变量、指针、数组、内存模型               | 写函数交换两个整数值（用指针）       |
| Day 2 | 结构体与联合体、枚举                  | 模拟存储一个传感器数据结构体        |
| Day 3 | 函数与宏                        | 用宏定义最大值函数 `MAX(a,b)`  |
| Day 4 | `volatile`、`const`、`static` | 分析为何中断标志要用 `volatile` |
| Day 5 | 小项目：命令行温度换算器（C 实现）          | 输入摄氏度输出华氏度            |
| 周末    | 复盘 + 写总结文档                  | 上传 GitHub，记录遇到的 C 坑点  |

---

#### **第 2 周：电子电路与开发环境**

**目标：** 掌握电路基础，能独立点亮 LED。
**每日任务：**

| 天数    | 任务                                  | 练习             |
| ----- | ----------------------------------- | -------------- |
| Day 1 | 电压、电流、电阻、电容、电感基本概念                  | 画一个简单串联电路并计算电流 |
| Day 2 | 看懂电路图与元器件符号                         | 识别电阻、电容、晶振、二极管 |
| Day 3 | 安装 STM32CubeIDE / PlatformIO / Keil | 创建空工程          |
| Day 4 | LED 接口与 GPIO 输出模式                   | 点亮 LED，延时闪烁    |
| Day 5 | 按键输入（GPIO 输入模式）                     | 实现：按键控制 LED 开关 |
| 周末    | 复盘：编译烧录流程 + 电路理解                    | 画 LED + 按键原理图  |

---

#### **第 3 周：定时器与中断**

**目标：** 能用定时器让系统自动闪烁或响应事件。

| 天数    | 任务                  | 练习                 |
| ----- | ------------------- | ------------------ |
| Day 1 | 定时器基础与时钟系统          | 用 SysTick 每秒闪烁 LED |
| Day 2 | NVIC 中断控制器原理        | 在中断中切换 LED 状态      |
| Day 3 | 外部中断（EXTI）          | 按键触发中断点亮灯          |
| Day 4 | 优先级与去抖动处理           | 软件消抖方案             |
| Day 5 | 小项目：定时闪烁 + 外部中断控制   | 实现“按一次切换闪烁模式”      |
| 周末    | 写笔记 + 自测题（时钟树/中断流程） |                    |

---

#### **第 4 周：串口与调试**

**目标：** 使用串口调试输出，学会打印和交互。

| 天数    | 任务                    | 练习               |
| ----- | --------------------- | ---------------- |
| Day 1 | UART 基础（TX/RX、波特率）    | 配置 UART 发送字符串    |
| Day 2 | 串口接收与中断               | 输入命令回显           |
| Day 3 | 重定向 printf            | 使用 printf 打印调试日志 |
| Day 4 | 使用 minicom / PuTTY 调试 | 实时查看调试输出         |
| Day 5 | 小项目：UART 命令行控制 LED    | 输入 on/off 控制 LED |
| 周末    | 复盘 + 画时序图             |                  |

---

### **第 2 阶段：外设与驱动（第 5–10 周）**

目标：掌握常见外设（I²C/SPI/ADC/PWM），能独立写驱动。

#### **第 5–6 周：ADC、PWM 与定时采样**

* ADC 模拟信号采集，PWM 控制亮度
* DMA 基础概念

**小项目：** 用电位器控制 LED 亮度
**检测点：** 画出 ADC-DMA 流程图

---

#### **第 7–8 周：I²C 与 SPI 总线**

* I²C 通信协议原理与时序
* 连接温湿度传感器（如 SHT30 / BME280）
* SPI 驱动 OLED 屏显示传感器数据

**小项目：**
传感器 → MCU → OLED 实时显示温湿度。

---

#### **第 9–10 周：DMA 与低功耗**

* DMA 传输机制（内存到外设）
* 低功耗模式（Sleep/Stop/Standby）
* 电源域与唤醒机制

**小项目：**
定时器触发 ADC + DMA 采样，睡眠 1s 醒来上报。

---

### **第 3 阶段：RTOS 实时操作系统（第 11–14 周）**

目标：理解任务调度与 FreeRTOS API。

#### **第 11–12 周：FreeRTOS 基础**

* Task、Queue、Semaphore、Mutex
* 优先级反转与调度机制
  **小项目：**
* 一个任务采集数据
* 一个任务打印日志
* 队列传输数据

#### **第 13–14 周：定时与通信**

* 软件定时器、事件组
* 串口 + 传感器 + OLED 多任务协调
  **小项目：** FreeRTOS 综合项目（多任务气象站）

---

### **第 4 阶段：系统进阶（第 15–20 周）**

目标：理解 Bootloader、OTA、通信协议、文件系统。

#### **第 15–16 周：Bootloader 与固件更新**

* 启动流程、向量表重映射
* 串口下载/更新固件
  **小项目：** 实现简单 Bootloader，从 UART 加载应用。

#### **第 17–18 周：通信协议**

* UART/TCP/HTTP/MQTT/Modbus 协议栈
* ESP32/STM32 + Wi-Fi 模块（AT 命令）
  **小项目：** 上传温度数据到本地服务器。

#### **第 19–20 周：文件系统与安全**

* FATFS 文件系统
* 基础加密（AES、CRC、校验）
  **小项目：** 日志存储与完整性验证。

---

### **第 5 阶段：嵌入式 Linux（第 21–24 周，可选）**

目标：了解 Linux 驱动开发与系统裁剪。

#### **第 21–22 周：交叉编译与文件系统**

* 使用 Buildroot 或 Yocto 构建系统
* 熟悉根文件系统结构

#### **第 23–24 周：驱动开发入门**

* 字符设备驱动
* 使用 sysfs 输出数据
  **小项目：** 在树莓派上写一个简单的 LED 驱动模块。

---

## 📘 学完你将具备的能力

✅ 独立配置 MCU 工程、烧录、调试
✅ 读懂常见外设数据手册并写驱动
✅ 用 FreeRTOS 设计任务结构
✅ 能做 OTA、低功耗、通信等中高级嵌入式功能
✅ 能阅读并调试 Linux 驱动源码
