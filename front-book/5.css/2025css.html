Invoker Commands（调用命令）

简介： 允许直接在HTML元素上用command属性声明交互命令，无需JS即可实现常见交互。
用法：
  • 在元素上添加 command 属性，如 <button command="alert('hi')">
  • 可配合 commandtarget 指定目标，如 command="toggle" commandtarget="#id"
  • 浏览器原生支持时无需JS，当前演示自动降级为JS实现

:has() 选择器

简介： :has() 是父选择器，可根据子元素状态选中父元素。
用法： div:has(input:checked) 选中包含已勾选input的div。

color-mix() 颜色混合

简介： color-mix() 可在CSS中直接混合两种颜色，支持多色空间。
用法： background: color-mix(in srgb, red 50%, blue)
red 50% + blue

变量字体（Variable Font）

简介： 变量字体允许通过CSS属性动态调整字体粗细、宽度、斜体等。
用法： font-variation-settings 或直接调节 font-size、font-weight。

锚定位（anchor positioning）

简介： 可让弹窗、气泡等元素锚定到其它元素，自动对齐。
用法： <div popover anchor="anchor-btn"> 让弹窗锚定按钮。

@scope 局部样式作用域

简介： @scope 可限定样式只作用于特定区域，防止全局污染。
用法： @scope (#scope-demo) { ... }
